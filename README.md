# Kemp & Kerrigan blog

Blog for Kemp & Kerrigan Opticians, Fulwood, Sheffield. Built with Jekyll and published free by GitHub Pages from the `main` branch.

- Preview: https://springviewmarketing.github.io/kemp-kerrigan-blog/ (hidden from search engines)
- Final address: https://blog.kempkerrigan.co.uk (not connected yet)
- Main practice site: https://kempkerrigan.co.uk

Posts live in `_posts/`. Rules for design, content, SEO and how to publish are in `CLAUDE.md`.
